# AI Transparency Notice

This project was developed with the assistance of AI tools. In the interest of transparency, we disclose the AI technologies used during the development process.

## AI Tools Used

### Requirements Engineering

**EARS (Easy Approach to Requirements Syntax)** was used to structure and formalize the requirements for this project. EARS provides templates for writing clear, unambiguous requirements using patterns like:
- Ubiquitous requirements ("The system shall...")
- Event-driven requirements ("When [trigger], the system shall...")
- State-driven requirements ("While [state], the system shall...")
- Optional requirements ("Where [feature], the system shall...")

### Specification and Planning

**GitHub Speckit** was used for:
- Feature specification generation
- Implementation planning and task breakdown
- Requirements checklists and validation
- Cross-artifact consistency analysis

### Code Generation and Development

**Claude Code with Opus 4.5** (Anthropic) was used for:
- Code generation and implementation
- Documentation writing
- Code review and refactoring suggestions
- Docstring and test generation

## Human Oversight

While AI tools assisted in the development process, all code and documentation have been reviewed and approved by human maintainers. The final responsibility for the correctness, security, and quality of this software lies with the human contributors.

## Continuous Improvement

We believe in transparency about AI usage in software development. As AI tools evolve, we will continue to update this notice to reflect any changes in our development practices.
