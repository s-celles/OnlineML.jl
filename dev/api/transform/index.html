Transformers

Online feature preprocessing transformers.

Scalers

OnlineML.Transform.StandardScaler — Type
StandardScaler{T<:AbstractFloat} <: Transformer{AbstractVector{T}}

Online standardization (z-score normalization).

Transforms features to have zero mean and unit variance.

Example

julia> scaler = StandardScaler()
StandardScaler: n=0 | value=Variance[]

julia> fit!(scaler, [1.0, 2.0]);

julia> transform(scaler, [1.0, 2.0])
2-element Vector{Float64}:
 0.0
 0.0

julia> nobs(scaler)
1

OnlineML.Transform.MaxAbsScaler — Type
MaxAbsScaler{T<:AbstractFloat} <: Transformer{AbstractVector{T}}

Online feature scaler that divides by maximum absolute value.

Scales features to the range [-1, 1] by dividing by the maximum absolute value seen for each feature. Useful for data that is already centered at zero.

Example

julia> scaler = MaxAbsScaler()
MaxAbsScaler: n=0 | features=0

julia> fit!(scaler, [2.0, -4.0, 1.0]);

julia> transform(scaler, [2.0, -4.0, 1.0])
3-element Vector{Float64}:
  1.0
 -1.0
  1.0

julia> nobs(scaler)
1

Reference

Scales each feature by its maximum absolute value, similar to sklearn.preprocessing.MaxAbsScaler but for streaming data.

OnlineML.Transform.TargetEncoder — Type
TargetEncoder{Y} <: OnlineStat{Tuple{Any, Y}}

Online target encoder with smoothing for categorical features.

Encodes categories based on the mean target value for that category, with Bayesian smoothing to handle rare categories.

Parameters

  • smoothing::Float64 = 1.0 - Smoothing parameter (higher = more regularization)

Example

julia> encoder = TargetEncoder{Float64}(smoothing=10.0)
TargetEncoder: n=0 | value=(sums = Dict{Any, Float64}(), counts = Dict{Any, Int64}())

julia> fit!(encoder, (:a, 1.0));

julia> fit!(encoder, (:b, 0.0));

julia> nobs(encoder)
2

Examples

Standard Scaler

using OnlineML.Transform: StandardScaler

scaler = StandardScaler()

for x in data_stream
    x_scaled = fit_transform!(scaler, x)
end

# For new data (don't update statistics)
x_new_scaled = transform(scaler, x_new)

One-Hot Encoder

using OnlineML.Transform: OneHotEncoder

encoder = OneHotEncoder()

for x in categorical_stream
    x_encoded = fit_transform!(encoder, x)
end
