Pipeline

Pipeline composition for online ML workflows.

OnlinePipeline

OnlineML.Pipeline.OnlinePipeline — Type
OnlinePipeline{T<:Tuple} <: Learner{AbstractVector, Any}

Sequential composition of transformers and a final learner.

Transformers are applied in order, with each transforming the input before passing to the next component.

Example

julia> pipe = OnlinePipeline(StandardScaler(), LogisticRegression())
OnlinePipeline: n=0 | value=(StandardScaler: n=0 | value=Variance[], LogisticRegression: n=0 | value=(weights = Float64[], bias = 0.0))

julia> fit!(pipe, ([1.0, 2.0], 1));

julia> predict(pipe, [1.0, 2.0])
1

julia> nobs(pipe)
1

ColumnTransformer

OnlineML.Pipeline.ColumnTransformer — Type
ColumnTransformer <: OnlineStat{Any}

Apply different transformers to different columns of the input.

Parameters

  • transformers - Vector of (name, transformer, columns) tuples
    • name - String identifier for this transformer
    • transformer - The transformer to apply
    • columns - Either:
      • Integer indices: [1, 2] for columns 1 and 2
      • Range: 1:3 for columns 1-3
      • Symbol: :all for all columns

Example

ct = ColumnTransformer([
    ("scaler", StandardScaler(), [1, 2]),
    ("encoder", OneHotEncoder(), [3])
])
fit!(ct, [1.0, 2.0, :a])
transform(ct, [3.0, 4.0, :b])

Examples

Basic Pipeline

using OnlineML.Pipeline
using OnlineML.Transform: StandardScaler
using OnlineML.Linear: LogisticRegression

# Create pipeline with |> operator
pipeline = StandardScaler() |> LogisticRegression()

# Train
for (x, y) in data_stream
    fit!(pipeline, (x, y))
end

# Predict
y_pred = predict(pipeline, x_new)

Multi-Step Pipeline

using OnlineML.Pipeline
using OnlineML.Transform: StandardScaler, OneHotEncoder
using OnlineML.Linear: LogisticRegression

# Chain multiple transformers
pipeline = StandardScaler() |> OneHotEncoder() |> LogisticRegression()

Parallel Feature Processing

using OnlineML.Pipeline: TransformerUnion
using OnlineML.Transform: StandardScaler, MinMaxScaler

# Apply multiple transformers and concatenate
union = TransformerUnion(StandardScaler(), MinMaxScaler())

for x in data_stream
    x_transformed = fit_transform!(union, x)
    # x_transformed contains both scaled versions
end

Column Selection

using OnlineML.Pipeline: ColumnTransformer
using OnlineML.Transform: StandardScaler, OneHotEncoder

# Apply different transformers to different columns
ct = ColumnTransformer(
    StandardScaler() => 1:5,      # Scale columns 1-5
    OneHotEncoder() => 6:10       # Encode columns 6-10
)
