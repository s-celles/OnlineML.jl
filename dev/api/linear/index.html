Linear Models

Linear models for online regression and classification.

Regression

OnlineML.Linear.Regression — Type
Regression{T<:AbstractFloat} <: Learner{AbstractVector{T}, T}

Online linear regression using recursive least squares. Wraps OnlineStats.LinReg for incremental fitting.

Example

julia> model = Regression()
Regression: n=0 | value=Float64[]

julia> fit!(model, ([1.0, 2.0], 3.0));

julia> nobs(model)
1

Classification

OnlineML.Linear.LogisticRegression — Type
LogisticRegression{T<:AbstractFloat, O} <: Learner{AbstractVector{T}, Int}

Online logistic regression using gradient descent with configurable optimizer.

Parameters

  • optimizer: Optimisers.jl optimizer (default: Adam(0.01))
  • l1: L1 regularization strength (default: 0.0)
  • l2: L2 regularization strength (default: 0.0)

Example

julia> model = LogisticRegression()
LogisticRegression: n=0 | value=(weights = Float64[], bias = 0.0)

julia> fit!(model, ([1.0, 2.0], 1));

julia> predict(model, [1.0, 2.0])
1

julia> nobs(model)
1
OnlineML.Linear.Perceptron — Type
Perceptron{T<:AbstractFloat} <: Learner{AbstractVector{T}, Int}

Online Perceptron classifier with configurable learning rate.

Parameters

  • η: Learning rate (default: 1.0)

Example

julia> model = Perceptron(η=0.5)

julia> predict(model, [1.0, 2.0])
1

julia> nobs(model)
1
