Naive Bayes

Online Naive Bayes classifiers.

Gaussian Naive Bayes

OnlineML.Bayes.GaussianNB — Type
GaussianNB{T<:AbstractFloat} <: Learner{AbstractVector{T}, Int}

Online Gaussian Naive Bayes classifier.

Maintains per-class, per-feature Gaussian distributions using online mean and variance estimation.

Example

julia> model = GaussianNB()
GaussianNB: n=0 | value=Dict{Int64, Vector{Variance}}()

julia> fit!(model, ([1.0, 2.0], 1));

julia> predict(model, [1.0, 2.0])
1

julia> nobs(model)
1

Bernoulli Naive Bayes

BernoulliNB{T<:AbstractFloat} <: Learner{AbstractVector{T}, Int}

Online Bernoulli Naive Bayes classifier for binary features.

Parameters

  • alpha::Float64 = 1.0 - Laplace smoothing parameter

Example

julia> model = BernoulliNB(alpha=1.0)

julia> fit!(model, ([1.0, 0.0], 1));

1

julia> nobs(model)
1

Examples

using OnlineML.Bayes: GaussianNB

model = GaussianNB()

for (x, y) in data_stream
    fit!(model, (x, y))
end

y_pred = predict(model, x_new)
probs = predict_proba(model, x_new)
